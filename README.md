# 日签云端推送系统

**电脑关机也能收到**：GitHub Actions 每天北京时间 07:25 自动触发，把当天封面图和提醒文字推到普通微信。

## 当前方案（v2，纯微信，无需企业微信）

- **主通道**：Server酱 → 微信服务号，正文含图片（jsDelivr CDN）+ 全部文案
- **备用通道**：PushPlus → 微信服务号，同样含图 + 文案
- 两条通道互相独立，一条挂了另一条照送
- 图片存在仓库 `images/` 目录，走 jsDelivr CDN 公网链接，手机长按可存相册
- 旧的企业微信通道代码保留但默认不用（填了 Webhook 才会发）

仓库：`https://github.com/jingxian1931/jiushu-daily-push`（公开，因为微信要能抓到图片；密钥不进代码）

---

## 一次性配置（约 5 分钟）

### 第 1 步 · Server酱（主通道，必填）

1. 打开 `https://sct.ftqq.com`，微信扫码登录（免实名）
2. 复制 SendKey（`SCT` 开头的一串）
3. **微信里关注并绑定它的服务号**，否则收不到消息
4. 免费版每天 5 条，日签每天 1 条，够用

### 第 2 步 · PushPlus（备用通道，强烈建议也配上）

1. 打开 `https://www.pushplus.plus`，微信扫码登录
2. 首页「一对一推送」里复制 token
3. 关注它的公众号
4. 免费版每天 200 条，实名认证需 3.9 元（不实名免费额度少些，个人够用）

### 第 3 步 · 填 GitHub Secrets

仓库 → `Settings` → `Secrets and variables` → `Actions` → `New repository secret`：

| Secret 名称 | 填什么 | 必填 |
|---|---|---|
| `SERVERCHAN_KEY` | 第 1 步的 SendKey | 是 |
| `PUSHPLUS_TOKEN` | 第 2 步的 token | 建议 |
| `IMAGE_URL_BASE` | 自定义图床前缀；留空则用 jsDelivr CDN | 否 |
| `WECOM_WEBHOOK` | 企业微信 Webhook（若以后注册了企微） | 否 |

## 日常使用

全自动，无需电脑。手机收到后按消息里的 6 步操作发贴图。最后一步「发表」始终人工点击。

电脑开着时，本地 07:25 提醒保留作第三重保险。

## 内容更新（12-05 之后）

1. 编辑 `data/daily_content.json`，照格式加新条目
2. 新封面图上传两张：
   - `assets/dayXX.b64`（`base64 -w0 图.png > assets/dayXX.b64`），供企微备用通道
   - `images/图.png`（原图），供微信通道内嵌
3. commit + push，次日生效

## 故障排查

| 现象 | 处理 |
|---|---|
| Actions 日志「未配置密钥」 | Secrets 名称拼错，必须一字不差 |
| 微信没收到 | 检查是否关注/绑定了对应服务号；当天免费额度是否用完 |
| 图片不显示 | jsDelivr 有约 24h 缓存，新图刚传可能要等；或检查文件名是否一致 |
| 推送延迟几分钟 | GitHub 高峰排队，正常 |
| 定时任务某天没跑 | 公开仓库 60 天无活动会被暂停；日签每天触发即算活动 |

---

## 合规与安全

- 密钥只存 Secrets，不进代码/日志
- 只推送给账号本人，不对外群发，不调用公众号发布接口
- 图片与文案均为已公开的日签内容
- 仓库公开仅为让微信抓取图片，代码里无任何敏感信息
